# Bhumika Gaba — Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons. It includes light and dark themes, an editorial project showcase, education and learning sections, and a custom pointer on supported desktop devices.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Project descriptions and links: `src/data.ts`
- Portfolio sections and profile copy: `src/components/`
- Theme colors, layout, and interactions: `src/index.css`, `src/glass.css`, and `src/reference-refinement.css`
- Resume link: `src/components/Header.tsx`
- Profile and project images: `public/`
